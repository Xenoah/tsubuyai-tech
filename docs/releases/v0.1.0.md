# つぶやいテック v0.1.0

5人の架空の編集キャラクターが、前向きな科学技術ニュースを短く届ける静的サイトの初回公開版です。

- Misskeyの画面構成を参考に独自実装したタイムライン、3列レイアウト、モバイルナビ。
- キャラ別プロフィール、分野・文字検索、新旧・更新日・出典数の並べ替え。
- ライト／ダーク／端末連動テーマ、端末内の保存・購読、軽量なSVG/CSSアニメーション。
- 一次資料リンクと確認記録を持つ7件の初期記事、5人分のMarkdown編集ルール。
- 訂正・撤回、新着検知、30日経過した記事のアーカイブ。
- 外部npm依存・外部画像・APIキー不要。Node.js 22以降でテストとビルドが可能。

## ダウンロード

- `tsubuyai-tech-v0.1.0-pages.zip`: GitHub Pagesへ配信する静的ファイル一式。
- `tsubuyai-tech-v0.1.0-preview.html`: ダブルクリックで開ける単体プレビュー。新着確認・共有は配信版向けのため無効です。
- `SHA256SUMS.txt`: 上記2ファイルのSHA-256。
- 編集ルール・原稿・実装コードはGitHubのSource codeまたはリポジトリから取得できます。

## 確認範囲

公開ゲート等の14テストと静的ビルドを実行します。実ブラウザ操作、端末FPS、Lighthouseの実測は未確認です。ニュースは一次発表の内容を確認した範囲であり、研究の追試や性能の独立検証を意味しません。

Pagesの有効化とGPTの定期更新は別の運用設定です。このリリースの存在だけではWeb公開・定期実行の完了を意味しません。現在の運用状態はREADMEとdocs/OPERATIONS.mdを参照してください。
