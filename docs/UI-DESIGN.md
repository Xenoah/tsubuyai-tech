# つぶやいテック UI設計

変更日: 2026-10-13。依頼: 「UIはmisskey.ioを参考に」。

## 参照した公開資料

- Misskey.io: https://misskey.io/
- Misskey Hub公式紹介（レスポンシブUI・テーマ・ウィジェット）: https://misskey-hub.net/ja/
- 公式ライトテーマの画面例: https://misskey-hub.net/img/hero/ss/tl.light.webp

Misskey.ioの公開ページはJavaScriptの有効化案内のみ取得できたため、配置・余白の参考にはMisskey Hubが公開している実際の画面例を使用した。ログイン後の現在のMisskey.io画面と完全に一致するという意味ではない。
参照画像は閲覧にのみ使用し、リポジトリ・配布物・サイトに含めない。

## 反映した構成

- 大画面: 左に常設ナビ、中央にタイムライン、右に独立したウィジェット。
- 丸みのある白いパネル、ライムの選択状態、余白のあるグレーの背景。
- 上部でホーム・購読・保存を切替。分野フィルタと並べ替えは投稿一覧のすぐ上に配置。
- 投稿のアバター、編集者、発表日を先頭に配置。出典、確認内容、保存、共有を本文の近くに集約。
- 1100px以下: 右のウィジェットを隠し、タイムラインの幅を優先。
- 830px以下: 左ナビをアイコン中心に縮小。
- 600px以下: 1列と下部ナビ。上部の検索・表示設定も使用可能。
- ライト／ダーク／端末連動を表示設定から選択。初期値は端末連動。

Misskeyのプログラム、テーマ定義、ロゴ、カスタム絵文字等は利用せず、既存の独自SVGと依存のないコードで実装する。
ニュースサイトに必要な操作を備え、利用者の投稿欄や架空のリアクション件数は表示しない。

## データと動き

ウィジェットの件数は公開データから集計する。タグは直近の掲載記事のみから抽出し、対応するホーム検索へ移動する。アクセス数や人気度の推測値は使わない。
日付はAsia/Tokyoで表示。表示中の更新確認と画面復帰時にも更新する。
保存・購読の既存localStorageキーは維持し、テーマ設定も端末内へ保存する。ログイン、外部送信、APIキー入力は不要。
アニメーションは既存のSVG/CSSを使用。画面外・非表示タブ・端末の低モーション設定・手動停止に対応。
